- [UI/UX] 설계서 §2 공통 알림 메시지 발송 체계의 단일 장애점이다. 발송에 실패하면 회원가입 완료 · 주문/결제 완료 · 회원 탈퇴 · 1:1 문의 답변 알림이 고객에게 닿지 않는다. 고객은 결제하고도 확인 문자를 못 받고 CS 문의가 폭증한다 — 그래서 이 배너를 스코어카드 바로 아래, 접히지 않는 위치에 고정한다

- [공통] "사람이 손을 대야만 다음으로 넘어가는" 항목만 모은다. 자동 처리되는 건은 넣지 않는다
