# 오픈 준비 운영 체크리스트 — 초안 1 (2026-11-05)

**목표: 11-23 오픈 때 운영 DB와 외부 서비스에 실제 서비스 데이터 · 설정이 갖춰져 있고, 테스트 값은 하나도 남지 않는 것.**

- 사람이 할 일만 모았다. 개발 AI 몫은 개발팀 2차 전달문(묶음 0 ~ 8)에 있고, 여기서는 '선행'으로만 적는다.
- 칸: **어디서** = 관리자 메뉴 경로 · 외부 사이트 / **값 · 근거** = 정본 근거, 바뀌는 값은 "사람이 입력할 값" / **확인** = 끝났는지 보는 방법 / **선행** = 먼저 끝나야 하는 일감 / **언제** = 개발 묶음 n QA 전 · 오픈 D-n · 당일 · 오픈 후 / **담당** = 비워 둠.
- 근거 약칭: 설계서 = 통합 상세 설계서, 19-10 = DEV_TRANSFER 19-10, 코드 = 개발 저장소 origin/dev(`config/services.php` · `config/app.php` · `routes/console.php`). 근거를 못 찾은 것은 **"정본에 없음, 확인 필요"**.
- 관리자 메뉴 경로는 개발 서버 SNB 이름 기준이다. 이름이 바뀌면 화면 코드로 찾는다.
