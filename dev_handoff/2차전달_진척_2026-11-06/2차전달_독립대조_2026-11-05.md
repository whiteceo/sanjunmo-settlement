## 3. 한 세션 완주 — 막힐 곳
1. 규칙 충돌: 전달문은 "마이그레이션을 만들고 실행 결과를 적는다"인데, 1차 회신은 팀 규칙대로 로컬 migrate 금지, check.sh 결과와 dev 반영 뒤 결과를 적게 했다. 마이그레이션 번호 배정 · 공지도 파트장 몫이었다.
2. 개발 서버 권한: Q8 시더 실행 · 2026-11 배치 재실행, 묶음 0 · 4 · 5의 개발 서버 데이터 · 약관 · 템플릿 등록은 개발 서버 쓰기 · 배포 권한이 있어야 한다. 권한이 없으면 묶음 0에서 멈춘다. → "권한이 없으면 실행할 명령 · SQL을 보고서 7절에 적고 다음으로" 같은 대체 경로를 넣는다.
3. 3-13: 정본은 "서버 로그 확인"이다. 개발 AI가 로그를 못 보면 원인 확정이 안 된다.

5. 권한 QA용 역할별 계정이 시드에 있는지 적혀 있지 않다. 375px 캡처에는 브라우저가 필요하다.
6. 분량: 번호 약 180개와 화면 170행 이상이다. 한 세션의 컨텍스트를 넘길 공산이 크다(추정). → "보고서 파일이 진행 상태. 끊기면 마지막 미완 묶음부터 이어 한다"는 재개 규칙을 넣는다.
