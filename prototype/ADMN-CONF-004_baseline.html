[ADMN-CONF-004] 카카오 알림톡 검수 프로세스 및 발송 제어 정책:
• 알림톡(ALIMTALK): SENS는 템플릿 생성 · 검수 요청 API를 제공하지 않으므로 템플릿 등록과 카카오 검수 요청은 SENS 콘솔에서 합니다. 이 화면에서는 SENS 템플릿 코드를 연결하고 [SENS 상태 동기화]로 검수 상태와 반려 사유를 받아오며, 검수 완료 · 정상(APPROVED) 템플릿만 실제 발송 트리거에 연결됩니다.
• 문자(SMS/LMS) 및 이메일(EMAIL): 별도 카카오 사전 검수 없이 등록 즉시 발송가능(APPROVED) 상태로 활성화되며, 알림톡 발송 실패 시 대체문자(Fallback) 문구로 자동 활용됩니다.
템플릿 코드 채널 / 성격 연동 도메인 / 트리거 템플릿명 및 본문 요약 SENS 검수 상태 대체문자(Fallback) SENS 동기화 / 수정 / 발송 액션
[ADMN-CONF-004-S1] 타겟 메시지 수동/예약 발송 가드레일:
[1] 알림톡 채널 선택 시 카카오 검수승인(APPROVED)이 완료된 템플릿만 발송할 수 있습니다.
[2] 광고성(AD) 메시지는 법정 금지 구간 21:00 ~ 익일 08:00(정보통신망법 제50조)에 보내지 않습니다. 발송이 21:00 전에 끝나도록 광고성 즉시 발송 · 예약 시작은 20:50까지만 받고(설정 가능한 기본값), is_marketing_agreed = true 수신 동의 회원만 자동 필터링됩니다.
그룹·태그 타겟은 회원 관리(USER-006)에서 만든 동적 그룹(매일 06:00 갱신)·정적 그룹(명단 고정)을 그대로 불러오며, 광고성 발송 시 마케팅 미동의 회원은 자동 제외됩니다.
