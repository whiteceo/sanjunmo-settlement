# 이용약관과 개인정보처리방침 정합성 검토

최초 검토 2026-11-04 · 최근 문안 반영 2026-11-06

사용자가 첨부한 Word 초안을 기준으로 기존 게시본과 설계서를 비교했다. 시행일 2026-11-23 및 합격환급 세부 정책 별도 확정은 유지한다. 가입 연령은 사용자 최종 결정에 따라 만 14세 이상만 허용하는 것으로 정리했다. 이전 아동 가입 허용 결정은 대체됐다. 이 문서는 문안의 변경 근거와 남은 확인 사항을 기록하며, 서비스 구현 또는 법률 검토가 완료됐음을 의미하지 않는다.

## 2026년 11월 5일 후속 결정 반영

아래는 2026-11-05까지의 사용자 확인 및 문안 반영 결과이며, 분석·광고 항목은 아래 2026-11-06 답변 반영 기록이 우선한다. 아래 최초 검토 이력은 당시의 변경 경위를 보존한 것이며, 이 절과 충돌하면 이 절을 따른다.

이번 작업은 위 문안 반영으로 한정하며 설계서 전면 개편, 신규 정책 설계, 개발 검증, 실제 사이트 배포·커밋·Drive 업로드는 포함하지 않는다. 첨부 원본 Word와 과거 PNG는 보존한다. 현재 자료에서 확인할 새 사용자 정책 결정은 없다.

남은 설정 확인은 실제 분석·광고 태그와 국외 처리·거부 수단, KT 가입 녹음 요금제의 보관기간·통화요약 기능 사용 여부로 한정한다. KT 녹음의 외부 처리 여부 자체는 공식 자료로 확인했으며, 인증계약의 아동 가입용 부모동의 지원 확인 과제도 종료했다. 별도 업체 문의는 발송하지 않았다.

KT 조사 근거(2026-11-05 직접 열람): [통화매니저 최신 개인정보처리방침](https://open.bizphone.co.kr/board_notice/read.jsp?tbl=faq&seq=60&search_word=&page=1&row=0)은 2026-10-06 시행본이다. 제2조의 [수집·보관 표](https://ktimg.byto.com/202610/per_02.png)는 일반 통화레코딩도 음성파일·수발신 번호·통화시각을 처리하고 가입 요금제별로 보관함을 명시한다. 제5조의 [수탁자 표](https://ktimg.byto.com/202609/per_06.png)는 KT디에스의 운영·민원처리 및 KT클라우드의 일반·AI 통화레코딩 클라우드 인프라 제공을 명시한다. [통합 이용약관](https://open.bizphone.co.kr/board_notice/read.jsp?tbl=faq&seq=53&search_word=&page=1&row=0) 제23조⑥도 이용자에게 수탁받아 고객 전화를 녹취·처리하는 구조를 설명한다. 이를 근거로 직접 수탁자인 KT를 공개 위탁 표에 반영했으며, KT의 수탁업체를 산준모의 직접 계약 업체로 일괄 등록하지 않았다.

같은 최신 방침 제6조의 국외 이전은 통화요약 요청 시 텍스트를 미국 Microsoft에 전송하는 내용이다. 산준모에서 해당 기능을 실제 사용한다는 증거는 확보하지 못했으므로 실제 국외 이전 표를 추정하여 추가하지 않았다. 회사 PC 보관 3년은 기존 회사 정책이며 KT 가입 요금제의 보관기간을 3년으로 확정한 것이 아니다.

조사 근거: [이니시스 통합인증 공식 개발가이드](https://manual.inicis.com/sa/auth.html)는 전자서명과 결과 반환을 제공하지만 현 계약 활성화나 대리관계 확인을 증명하지 않는다. [패스트캠퍼스 공식 방침](https://next.fastcampus.co.kr/info/policies/privacy)은 활용 목적만 참고했다. [Google 공식 지역별 수집 안내](https://support.google.com/analytics/answer/11598602)는 수집센터에서 처리 서버로 전달하는 구조를 설명하므로 국내 인프라와 Google 처리를 동일시하지 않는다.

## 2026년 11월 6일 마케팅 담당자 답변 반영

근거는 사용자가 이 채팅에 전달한 파트장 답변이다. 외부 업체의 공식 설명과 산준모의 실제 설정 확인을 구분한다. 문안 변경 범위는 개인정보처리방침 제1·9조 및 내부 안내 기록이며 이용약관·FAQ·DOCX와 백오피스는 이번 작업에서 변경하지 않았다.

| 받은 답변 | 문안 반영 및 판단 |
| --- | --- |
| GA·픽셀 등 각 매체 분석 도구 일체 | GA4와 매체 픽셀 사용을 반영. 어떤 픽셀인지 제공업체가 특정되지 않아 Meta·네이버·카카오 등의 이름을 임의 기재하지 않음. 기존 Meta 1차 미사용 문구도 유지 근거가 불충분해 제거 |
| GA4 14개월 | 담당자 확인으로 기록. 직접 설정 화면을 검증한 것은 아님. GA4의 사용자·이벤트 단위 보유기간으로 한정하고 모든 매체의 보유기간으로 확대하지 않음 |
| 고객 탈퇴 시점부터 1년 이내 삭제 | 분석·광고 이용기록의 삭제 기준으로 반영. 가입정보 파기·법정 거래기록·제재 기록 등 기존 기간을 일괄 변경하지 않음. 자사 저장소·GA4·다른 매체 중 어디에 적용되는지와 탈퇴 식별·삭제 연동의 실제 구현은 답변에 없음. 설정 14개월만으로 탈퇴 후 1년 내 삭제가 자동 보장된다고 판정하지 않음 |
| 기기·지역·브라우저 등 수집 가능한 정보 일체 | 확인된 기기·지역·브라우저 정보를 기존 구체적 항목에 추가. 포괄적인 ‘정보 일체’를 수집 허용 문구로 사용하지 않음. 직접 식별정보 전송 금지 정책 유지 |
| 국외 처리·거부 방법 미확인 | 완료로 바꾸지 않음. Google 공식 분석 차단 부가 기능은 확인하여 안내하되, 다른 매체의 픽셀이나 사이트의 실제 동의·거부 기능까지 해결된 것으로 간주하지 않음 |

공식 근거: [Google 데이터 보관 안내](https://support.google.com/analytics/answer/7667196?hl=ko)는 14개월 설정의 적용 범위와 새 활동 시 보관기간 재설정을 설명한다. [Google 리전 수집 안내](https://support.google.com/analytics/answer/11598602?hl=ko)는 위치정보 산출 및 처리 서버 전달 구조를 설명한다. [Google 분석 차단 안내](https://support.google.com/analytics/answer/181881?hl=ko)는 부가 기능이 다른 분석 도구까지 차단하지 않는다고 명시한다. 2026-11-06 확인.

## 이번 문안의 완료 기준

고객이 가입·구매 전에 알아야 할 이용 조건과 개인정보 처리 내용을 설명하는 데 필요한 범위로 한정한다. 실제 제공하지 않는 기능, 내부 처리 절차, 미확정 상품 조건은 공개 답변에 추가하지 않는다. 개발·계약의 미확인 사실을 문안만으로 완료 처리하지 않는다.

- 약관: 가입·미성년자, 구매·공급, 수강기간, 취소·환불·교재 반품, 포인트·쿠폰, 탈퇴·분쟁 안내가 연결되어 있는지 확인.
- 개인정보처리방침: 실제 처리 목적·항목·기간, 수탁자, 파기, 이용자 권리·문의창구, 적용되는 분석·광고와 국외 처리 안내를 확인.
- FAQ: 가입부터 결제·학습·배송·환불·문의까지 고객의 다음 행동을 안내하며, 약관과 다른 조건이나 내부 검토 메모를 넣지 않음.

비교 자료는 [패스트캠퍼스 공식 방침](https://next.fastcampus.co.kr/info/policies/privacy)과 [에듀윌 공식 방침](https://company.eduwill.net/main/privacy)이다. 항목 구성과 안내 범위를 비교하되 타사 기능·금액·기간을 산준모 정책으로 가져오지 않는다. 공개 문서의 분량을 늘리는 대신 실제 처리와 맞는지를 완료 기준으로 삼는다.

일반상품의 약관·FAQ는 현재 구성으로 충분하며 새 정책 항목을 추가할 필요는 없다는 편집 판단이다. 개인정보처리방침의 확정 게시 여부는 위에 남은 설정 확인 중 실제 개인정보 처리에 영향을 주는 결과를 반영한 뒤 판단한다. 확인되지 않은 분석·광고 기능을 문구만 추가해 활성화한 것으로 간주하지 않는다.

미성년 유료계약 안내 근거: [민법 제5조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1031397911)를 2026-11-05 확인했다. 만 14세 이상 가입 허용이 모든 유료계약의 법정대리인 동의 면제를 뜻하지 않도록 안내를 구분했다.

## 작업 범위와 검증

첨부 Word 원본 보존, 현행 Markdown 2개 및 과거 초안 안내, 설계서의 해당 정책 절, README의 약관 안내·합격환급 요약, 개발팀 전달 19-13, 프로젝트 상태를 갱신한다. 구현 코드·정산 계산기·프로토타입은 이 작업에서 수정하지 않는다. 조문 연속성·상호 참조·표 열 수·문서 링크·Word 원본 해시 및 변경 범위를 확인한다. 실제 가입 연령 제한·환급·GA4·파기 배치의 동작 검증은 별도 개발 작업이다.
