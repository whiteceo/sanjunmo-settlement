위 두 파일이 이번 GitHub 공유용 최종 문안이다. 이용약관·방침 본문과 내부 확인 기록은 별도 파일로 관리한다. 이 문안 정리는 실제 서비스 게시 또는 남은 운영 사실 확인까지 완료했다는 의미가 아니다.

## 반영 기준

- 고객센터: 평일 10:00~17:00, 점심시간 12:00~13:00.
- 가입 연령: 만 14세 이상만 허용. 사용자 후속 확인에 따라 아동 가입 허용 결정을 대체하며, 일반·SNS 가입 모두 본인인증 생년월일 기준으로 적용. 아동 가입용 법정대리인 동의 절차 및 정보 수집 문구 삭제. 만 14세 이상 미성년자의 유료계약 안내는 구분하여 유지.
- 본인인증: KG이니시스 통합인증과 KG파이낸셜(구 KG모빌리언스) PASS 휴대전화 본인확인을 각각 별도 계약한 것으로 사용자 확인. DI 신청·CI 미신청을 문안에 반영. 사용자가 아동 가입용 부모동의 확인 기능이 없음을 확인했으므로 해당 기능 확인 과제는 종료.
- '환급'은 합격환급 상품 관련 문맥에서만 사용. 일반 취소·반품 등은 '환불' 또는 '반환' 사용.
- 합격환급 상품의 세부 조건·세무 처리는 해당 상품 판매 전 별도 확정·고지.
- 개인정보처리방침 위탁 표에 기존 수탁자와 업무를 기재. '계약 법인명'이라는 별도 공개 항목은 추가하지 않음. 기존 업체명을 다시 수집하는 대신 누락·불일치가 있는 관계만 확인.
- 웰컴 혜택: 일반 탈퇴 후 1년이 지나 판정용 DI 해시가 파기된 뒤 재가입하면 재지급 허용. FAQ Markdown·Word에 반영.
- 전화상담 녹음: KT의 통화 녹음·서비스 제공·보관 업무를 위탁 표에 반영. 회사가 별도로 보관하는 파일은 회사 PC에 저장하고 통화일부터 3년 후 파기. KT 공식 방침에서 일반·AI 통화레코딩의 음성파일 처리 및 클라우드 인프라 제공 구조를 확인했으므로 외부 처리 여부 자체를 미확인 항목으로 남기지 않음.
- 분석·광고 활용 목적은 서비스 개선·통계·고객 분석·광고효과 측정·맞춤형 광고까지 포함. 타사 도구 목록이나 보유기간을 그대로 도입한 것은 아님.
- 2026-11-06 전달받은 파트장 답변: GA·픽셀 등 매체 분석 도구 사용, GA4 보유 설정 14개월, 접속기기·지역·브라우저 등 자동 수집 정보 처리, 탈퇴 후 1년 이내 삭제 기준 반영. 구체적인 픽셀 제공업체명은 답변에 없어 추정하지 않음. 종전 Meta Pixel 1차 미사용 문구는 이번 포괄적 픽셀 사용 답변과 양립 여부가 확인되지 않아 공개 문안에서 제거했으며, Meta 사용이 확정됐다는 뜻은 아님.
- QA 기록은 이번 문안 확정의 판단 근거에서 제외. 구현·배포 검증은 후속 작업으로 구분.

## 문안 완성 범위

2026-11-06 패스트캠퍼스·에듀윌 공개 방침의 항목 구성과 Google·Microsoft의 공식 이용자 통제 안내를 비교하여 개인정보처리방침 제9조를 정리했다. 처리 목적·항목·방법·도구·기간은 표로 모으고, 쿠키 차단·GA 차단·Google 광고 설정 및 개인정보 문의창구를 구체화했다. 시크릿 모드나 광고 맞춤설정 해제가 모든 수집을 차단한다고 안내하지 않는다. 타사 매체 목록·금액·기간·국외 이전 정보를 복사하지 않는다.

현재 파일은 백오피스 입력·내부 검토를 위한 문안 완성본이다. 사용자 요청에 따라 국외 이전 조항은 사전 안내·필요한 동의·문의 및 거부 요청의 일반 기준으로 간결하게 정리했으며, 국외 이전이 없다고 단정하거나 확인되지 않은 업체·국가를 추가하지 않았다. 이 표현은 실제 태그·국외 이전의 개별 사실을 확인했다거나 개인정보처리방침의 공개 적합성 검토까지 끝났다는 의미가 아니다. 공개 전 운영 사실 대조는 위 표로 한정하며 새로운 정책 질문을 늘리지 않는다.
