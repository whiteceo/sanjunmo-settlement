위 두 파일이 이번 GitHub 공유용 최종 문안이다. 이용약관·방침 본문과 내부 확인 기록은 별도 파일로 관리한다. 이 문안 정리는 실제 서비스 게시 또는 남은 운영 사실 확인까지 완료했다는 의미가 아니다.

## 반영 기준

- 고객센터: 평일 10:00~17:00, 점심시간 12:00~13:00.
- 만 14세 미만 아동의 가입 허용. 필요한 법정대리인 동의·확인에 관한 조문 포함.
- 본인인증 연동 기준: KG이니시스. 개인정보처리방침에 이미 적힌 업체명 유지. KG모빌리언스의 실제 참여·공개 여부는 확인 전 추정하여 추가하거나 관계를 단정하지 않음.
- '환급'은 합격환급 상품 관련 문맥에서만 사용. 일반 취소·반품 등은 '환불' 또는 '반환' 사용.
- 합격환급 상품의 세부 조건·세무 처리는 해당 상품 판매 전 별도 확정·고지.
- 개인정보처리방침 위탁 표에 기존 수탁자와 업무를 기재. '계약 법인명'이라는 별도 공개 항목은 추가하지 않음. 기존 업체명을 다시 수집하는 대신 누락·불일치가 있는 관계만 확인.
- QA 기록은 이번 문안 확정의 판단 근거에서 제외. 구현·배포 검증은 후속 작업으로 구분.

## 담당자에게 남은 질문

| 담당자 | 확인할 내용 |
| --- | --- |
| 본인인증 계약·연동 담당자 또는 KG이니시스 담당자 | KG이니시스 연동 외에 KG모빌리언스도 실제 개인정보 처리에 참여하는지, 참여하면 어떤 관계·업무이며 공개 목록에 어떻게 표기할지 |
| 고객센터·녹취 서비스 담당자 | 녹음 저장 위치, 외부 업체의 보관·접근 여부, 3년 후 삭제 방식. 외부 처리 업체가 있을 때만 누락 업체명 확인 |
| 서버·인프라 담당자 | 이미 기재된 AWS의 실제 서버·DB·백업 리전과 해외 저장·지원 접근 여부. 현재 기재와 실제 처리 주체가 다를 때만 명칭 정정 |
| 마케팅·GA4/GTM 담당자 | 실제 사용할 태그·수집 항목·보유 설정, 국외 처리·거부 방법, Meta Pixel·고객정보 매칭 미사용 여부 |

답변 후 문구 변경이 필요하면 개인정보 보호책임자·법무 담당자가 수탁자·국외 이전 안내를 확인한다. 법정대리인 동의 관련 안내 및 보관 근거의 검토도 이 역할이 담당한다. 점심시간과 아동 가입 허용 여부를 다시 결정할 필요는 없다. QA 질문은 위 목록에 포함하지 않았다.
