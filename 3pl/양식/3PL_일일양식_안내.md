# 물류 일일 양식 안내 (2026-11-03, white님 확인 · 정본 v3.2.49 반영)

- 파일: [빈 양식](/mnt/project-files/3pl/양식/3PL_일일양식_빈양식.xlsx) · [작성 예시](/mnt/project-files/3pl/양식/3PL_일일양식_작성예시.xlsx)
- 근거: 화면설계서 ADMN-ORD-002 3PL 엑셀 규격, 개발 코드 a8016168(DeliveryService·RefundService)
- 칸 색: **파란색 = 우리가 채움**, **노란색 = 낭주특송이 채워 회신**

## 주고받는 방법
1. 평일 14:00 전: 우리가 파일 하나(시트 3개)를 낭주특송에 메일로 보냅니다. CC 오스틴북스.
2. 평일 18:00: 낭주특송이 **같은 파일**의 노란 칸을 채워 회신합니다. 회수품 사진은 메일에 첨부합니다.
3. 운영자가 회신 파일을 관리자 화면 [송장 업로드]에 올립니다.

## 시트
| 시트 | 우리가 채움 | 낭주특송이 채움 |
|---|---|---|
| 발주 (배송요청, 맨 앞) | 개발 발주 파일 15칸 그대로 | 택배사코드(LOTTE) · 운송장번호 · 출고일자 |
| 취소 | 처리유형(주문 취소 / 배송지 변경) · 대상 주문 · 요청일시 · 사유 · 변경주소(배송지 변경일 때) | 처리결과(취소완료 / 이미출고) · 이미 나갔으면 운송장번호 · 확인일시 |
| 회수 | 환불번호 · 고객 주소 · 상품 · 수량 · 사유 | 회수운송장번호 · 입고일자 · 검수결과(정상 / 훼손) · 검수내용(개봉 · 필기 · 훼손 · 수량) · 사진(메일 첨부) |

## 지켜야 할 것 (어기면 업로드가 거부됩니다)
- **발주 시트를 맨 앞에** 둡니다. 시스템은 첫 시트를 읽습니다.
- 칸 이름(1행)을 바꾸지 않습니다. 칸을 더 붙이는 것은 괜찮습니다.
- 필터 · 셀 병합 · 수식을 쓰지 않습니다(다른 시트 포함).
- 운송장번호는 숫자만(하이픈 없이 10~14자리), 텍스트 서식. 출고일자는 `YYYY-MM-DD`.
- 출고하지 못한 줄(취소 · 재고 부족)은 운송장을 비워 두지 말고 **줄을 지운 뒤** 업로드합니다. 빈 운송장 줄은 오류(E03)로 셉니다.
- 다른 주문끼리 한 상자로 묶지 않습니다(같은 주문 여러 권은 같은 운송장 가능).

## 운영자 확인
- 18:00 회신에서 발주 줄마다 운송장이 왔는지, 취소 시트에 결과가 다 찼는지 봅니다.
- 이미출고 건은 반품(회수)으로 넘깁니다.
- 배송지 변경이 취소완료로 오면 출고 지시를 회수하고, 바뀐 주소로 다음 날 발주에 다시 넣습니다. 출고보류 요청은 따로 없습니다.
- 회수 시트 결과와 사진으로 관리자 화면 [3PL 입고 확인] · [검수]를 입력합니다(현재 수동).
