## 2. 코드별 상세

### 공통 속성 (모든 TX)
- 지방소득세율 = 소득세액의 10%(`local_income_tax_rate`, 11.1절 · 부록 B). 합산 실효율을 한 번에 곱하지 않는다(줄 276, 568).
- 세율 · 의제율 · 과세최저한 · 소액부징수 한도는 유효일자 기반 매트릭스 값이며 코드에 하드코딩하지 않는다(줄 537). 값은 `tax_table.json`의 `parameters`.
- 업종코드(`industry_code`): BUSINESS 라인만. 강의 R/S · 강의 대상 지원금 · 약정금 940903, 인세 · 매절 · 도서 대상 지원금 · 약정금 940100. OTHER는 NULL(줄 538).
- 마감 허용: `matrix_case_id IS NOT NULL AND tax_decision_status = DECIDED`만. PENDING_REVIEW 1건이라도 있으면 그 권리자 마감 차단(줄 411).

### TX-01 자사 권리자 (줄 418~423)
- 대상: `is_internal = true` 권리자. 공급 성격: 전체(강의 R/S · 도서 인세 · 매절 매출 귀속 · 매입 재판매 매출 귀속).
- 소득 구분: 없음 / 원천세: 없음 / VAT: 비대상 / 필요경비 · 과세최저한 · 소액부징수: 해당 없음.
- 증빙: 발행 제외, 정정 채널 제외(내부 대체 전표). 외부 대량이체 · 국세청 API 조회 제외. 연산은 일반 권리자와 동일 수행(줄 20).
- 보류 조건: 없음.

### TX-02 개인 프리랜서 · 강의 용역 R/S (줄 424~434)
- 대상: 개인(거주자). 공급 성격: 온라인 강의 수익 배분(R/S), 매출연동(R/S)형 개발지원금(Pipeline 5.1).
- 소득 구분: `income_category = BUSINESS`, `income_clause` 없음(있으면 저장 차단, 줄 62). 근거 소득세법 제127조 제1항 제3호.
- 원천세율: 소득세 3.0% → 지방소득세 = 내림(소득세 × 10%). 실효 3.3%는 검증 참고값일 뿐 계산에 쓰지 않는다.
- 필요경비 의제 · 과세최저한: 해당 없음(기타소득 전용). 소액부징수: 적용 제외(소득세 1천 원 미만도 전액 징수, 2024.7.1 이후 지급분). 지방세 소액 징수면제: 미적용.
- 부가세: 면세(인적용역, 부가세법 제26조 제1항 제15호 · 시행령 제42조 제1호). 가산 없음.
- 증빙: 사업소득 원천징수영수증 / 정정 채널 3-a. 신고: 사업소득 간이지급명세서 매월(지급일 다음 달 말일) + 지급명세서 연 1회(다음 해 3월 10일). 지방세 납세지: 지급지(본점 일괄).
- 보류: `main_work_external_labor = true` → `matrix_case_id = NULL` PENDING(줄 426, 535).

### TX-03 개인 프리랜서 · 교재 인세 · 매절 (줄 435~448)
- 공급 성격: 자사 발행 도서 저작권 인세, 저작권 양도 매절. 기본값 BUSINESS(`royalty_income_category_default`), 세율 · 서식 TX-02와 동일(3.0% → 10%, 소액부징수 제외).
- 부가세: 인세 면세(시행령 제42조 제1호 아목). 매절 면세는 "기준선, 개별 계약은 세무 자문 확인"(정본 확인 필요 7번).
- 기타소득 예외 분기(일시적 · 우발적 저술 한정, 계약원장 소명 + 재무책임자 승인):
  - C15 + `payee_is_author = true`: 의제율 60%. 필요경비 = 내림(과세표준 × 60%), 기타소득금액 = 과세표준 − 필요경비, 소득세 = 내림(기타소득금액 × 20%), 지방소득세 = 내림(소득세 × 10%). 실효 8.8%. 원천징수영수증은 금액 무관 발급.
  - C05 + `payee_is_author = false`: 의제 없음, 소득세 = 내림(지급액 × 20%), 지방소득세 = 내림(소득세 × 10%). 실효 22%.
  - 과세최저한: 기타소득금액 ≤ 50,000원이면 0원(`other_income_min_tax_amount`). 지급액 환산 임계 60% 의제 125,000원, 의제 없음 50,000원. 판정 단위 = `tax_threshold_unit_key`(월 집계 1건을 모든 거래의 1건으로 일괄 대체 금지).
  - 소액부징수: 예외 분기에는 적용(소득세 1천 원 미만 미징수).
  - 신고: 예외 분기는 간이지급명세서 대상 아님, 기타소득 지급명세서 연 1회(다음 해 2월 말일).
- 증빙: 원천징수영수증 / 채널 3-a.
- 적용 경계: 도서를 재화로 공급(위탁 · 사입)하면 TX-11 또는 TX-12.
- 보류: `main_work_external_labor = true`; 예외 분기에서 `income_clause` 미지정.

### TX-04 개인 프리랜서 · 비정기 약정금 (줄 449~456)
- 공급 성격: 비정기 약정금(전속금 · 일시금 · 분할형 개발지원금 · 수당). 계약 등록 시 지정한 `income_category` 적용.
- BUSINESS: 3.0% → 10%, 소액부징수 제외. OTHER + C19: 의제율 60%(실효 8.8%), 간이지급명세서 매월 대상(제164조의3 제1항 제3호). OTHER + C17: 의제 없음(실효 22%), 간이지급명세서 대상 아님, 지급명세서 연 1회만.
- 기타소득 과세최저한(기타소득금액 ≤ 50,000원 0원) · 소액부징수(소득세 < 1,000원 0원): OTHER에 적용.
- 부가세: 면세(TX-02와 동일, 고용 요건 판정 `main_work_external_labor`, 면세 배제되면 과세 전환). 증빙 원천징수영수증 / 채널 3-a.
- 매출연동(R/S)형 지원금은 TX-04가 아니라 TX-02(줄 456).
- 보류: `income_category` 미지정(검수 승인 차단) → NULL PENDING.

### TX-05 간이과세자 영수증 (tax_type_cd=02) (줄 457~463; 03권 줄 397)
- 판정: 국세청 API 응답(`tax_type_cd = 02`, `payee_tax_type = SIMPLIFIED_RECEIPT`, `tax_invoice_eligible_yn = false`). 금액 임계 4,800만 원은 로직에 사용하지 않는다.
- 공급 성격: R/S · 인세 · 매절 · 비정기 약정금 · 개발지원금. 도서 재화는 TX-11. 인적용역 해당 시 공급 성격을 인적용역으로 표기하고 원천징수 경로 적용.
- VAT: 미가산(공급대가 총액 기준 등록이 기본. 가산 약정은 예외 플래그 + 재무책임자 승인).
- 증빙: 영수증(카드 · 현금영수증) 대사 기록, 세금계산서 요청 제외. 정정 채널 3-b, 원천징수 대상 소득 정정은 3-a 병행.
- 원천징수 · 소득 구분 · 세율: "사업자 지위만으로 제외하지 않고 소득 성격으로 별도 판정"이라고만 하고 판정 기준을 정하지 않음. 정본 확인 필요 2번.

### TX-06 간이과세자 세금계산서 발급사업자 (tax_type_cd=07) (줄 464~469)
- 판정: `payee_tax_type = SIMPLIFIED_INVOICE`, `tax_invoice_eligible_yn = true`, 유효 시작 `invoice_apply_dt`. 상단 경계 초과 시 TX-07.
- VAT: 10% 과세. `vat_treatment` 분기(VAT_EXCLUDED: 내림(공급가액 × 10%) 가산 / VAT_INCLUDED: 공급가액 = 내림(총액 × 100/110), 부가세 = 총액 − 공급가액).
- 증빙: 전자세금계산서(권리자 발행 · 제출) / 채널 1(원천징수 대상 소득이면 3-a 병행).
- 원천징수: 별도 판정(공백, 확인 필요 2번). 자문(14.3) 확정 전 개인 인적용역 · 인세 · 지원금 지급분은 PENDING_REVIEW 후보 TX-06(줄 409, 535).

### TX-07 일반과세자 (tax_type_cd=01) (줄 470~476)
- 판정: `payee_tax_type = GENERAL`, `tax_invoice_eligible_yn = true`. 법인 · 단체가 인적용역 면세 대상이 아닌 강의 R/S · 약정금 · 지원금을 수취하는 경우도 TX-07.
- 공급 성격: 강의 R/S, 비정기 약정금, 개발지원금, 매절(개인사업자), 사업자 지위 도서 인세(개인사업자). 법인의 도서 인세 · 매절은 TX-09.
- VAT: 10% 과세, `vat_treatment` 분기(TX-06과 동일).
- 증빙: 전자세금계산서(권리자 발행) / 채널 1(개인 원천징수 병행 확정 시 3-a).
- 원천징수: 법인은 대상 아님(소득세 · 지방세 0). 개인 일반과세사업자는 14.3 자문 확정 전까지 후보 TX-07 + PENDING_REVIEW.
- 재무 처리: 지급 VAT 10%는 매입세액 불공제 원가(계산 영향 없음, 계정 구분만).

### TX-08 면세사업자 (tax_type_cd=04) (줄 477~483)
- 판정: `payee_tax_type = EXEMPT`, `tax_invoice_eligible_yn = false`.
- VAT: 면세 0%. 증빙: 전자계산서(권리자 발행 · 제출) / 채널 2(원천세 정정 동반 시 3-a 병행). 수정 세금계산서 요청 목록 적재 차단.
- 원천징수: 소득 성격 · 법령에 따라 별도 판정(공백, 확인 필요 2번).
- 적용 경계: 도서 재화 공급(위탁)은 TX-11(발행 주체가 당사 수취로, 채널 2→4).
- 보류: 수취인이 법인(`corp_no` 보유)이면서 면세 요건 미충족 과세 용역 라인 → 후보 TX-09(인세 · 매절) 또는 TX-07(강의 R/S · 약정금 · 지원금), PENDING_REVIEW(줄 409, 483, 533).

### TX-09 법인 · 단체 도서 인세 · 매절 (줄 484~490)
- 판정: 수취인이 법인 · 단체, 공급 성격이 도서 저작권 인세 · 매절. (법인 · 단체의 강의 R/S · 약정금 · 지원금은 TX-07.)
- 소득세 · 지방세 없음(소득세법 · 법인세법상 원천징수 대상 아님). `income_category` 처리는 정본 확인 필요 8번.
- VAT: 10% 과세(법인은 인적용역 면세 불가). `vat_treatment` 분기. 증빙: 전자세금계산서(권리자 발행) / 채널 1.
- 2계층 수취인 분할로 법인 소속사가 인세 수취해도 TX-09(줄 489).
- 보류: `tax_type_cd = 05·06`(비영리법인 · 고유번호 단체)과 `tax_type_cd = 04` 법인은 후보 TX-09 + PENDING_REVIEW(줄 409, 485).

### TX-10 비거주자 · 외국법인 (줄 491~493)
- 12장 따름. 국내 매트릭스 세율 · 증빙 규칙 적용 금지. 1차 오픈은 `is_resident = false` 계약 차단 또는 수기 격리. 엔진 동작: `matrix_case_id = NULL`, PENDING_REVIEW(줄 410, 535). 계산 안 함.

### TX-11 도서 재화 공급(위탁자 · 매입처) (줄 494~504)
- 우선 판정: 공급 성격이 재화(도서)이면 수취인 지위보다 먼저 TX-11(줄 412). `book_supply_type` 미지정이면 NULL + PENDING.
- 원천징수 없음(소득세법 시행령 제184조 제1항), `income_category = NULL`, `taxable_base` 미생성 → 신고 산출물에서 자동 배제.
- VAT: 도서 면세(부가세법 제26조 제1항 제8호 · 시행령 제38조). 도서 부가세 가산 없음.
- 증빙: 전자계산서, 발행 주체 공급자(당사 수취). 정정 채널 4(당사 수수료 세금계산서 정정 동반 시 1 병행).
- 위탁 수수료 부가세(9단계, 줄 267~268): 위탁 수수료 부가세 = 내림(당월 순 위탁 수수료 공급가액 × 10%). `consignment_fee_type = NET_DEDUCT`이면 위탁 실정산액 = 4단계 순 위탁 정산액 − 수수료 부가세, `GROSS_SETTLE`이면 위탁 실정산액 = 4단계 순 위탁 정산액(수수료 공급가액 · 부가세는 별도 매출채권 청구).

### TX-12 미등록 개인 도서 공급자 (줄 505~510)
- 기본: 계약 원장 등록 차단(엔진 입력에 올 수 없음). 예외 승인 시 수기 정산 격리, 자동 마감 경로 제외, 증빙불비 소명 기록 → 후보 TX-12 + PENDING_REVIEW(줄 409, 535).
- 원천세 · VAT 계산 없음. 원천징수로 증빙 대체 불가.

### TX-13 일반 과세 재화(소비재) (줄 511~517)
- 대상: 상품 마스터 상품 재화 라인(Pipeline 2.3). 수취인 TX-01 고정, 케이스는 TX-13.
- 원천징수 없음(`taxable_base` 미생성). VAT 10%(TAXABLE): Pipeline 2.3 인입 공식의 공급가액 · 부가세를 그대로 사용(9단계에서 재계산하지 않음, 줄 270).
- 증빙: 당사 발행 세금계산서 / 채널 1. 지급 0원(외부 자금 유출 없음).

## 3. 9단계(TAX) 의사코드 (정본 8.3절 9단계, 줄 260~284)

입력 이름은 03권 데이터 사전 컬럼명. 수식 설계 담당 SPEC.md 9단계 인터페이스와 이름이 다르면 SPEC 쪽 이름을 따르고 이 표를 맞춘다(작성 시점 SPEC.md 없음).

```
입력 (payee 한 명 · 라인 한 줄 단위; 8단계 산출 배열 + 1단계 PRE_TAX 배열)
  line:
    payee_id, line_kind ∈ {NEW, PRE_TAX_CARRY}   # 당월 신규 / 원귀속 세전 미지급 소득(1단계 전달)
    pipeline, supply_nature, supply_category ∈ {GOODS, SERVICE}
    taxable_base              # 8단계 산출(라인 분할액, EARNED 선급금 차감 후). 재화 라인은 생성 안 함(NULL)
    pending_negative_base     # 음수 조정 보류분
    income_category ∈ {BUSINESS, OTHER, NULL}, income_clause ∈ {C05,C15,C17,C19,NULL}
    payee_is_author, tax_threshold_unit_key
    vat_treatment ∈ {VAT_EXCLUDED(기본), VAT_INCLUDED}
    pre_tax_amount            # 세전 지급액(VAT 계산용)
  payee: is_internal, tax_type_cd, payee_tax_type, tax_invoice_eligible_yn, is_resident,
         main_work_external_labor, business_status, corp_no, book_supply_type
  params (tax_table.json.parameters):
         local_income_tax_rate=0.10, other_income_min_tax_amount=50000,
         small_amount_exemption_limit=1000, deemed_expense_rate{C15:.6,C19:.6,C05:0,C17:0},
         income_tax_rate{BUSINESS:.03, OTHER:.20}   # 실제 지급(상계 · 지급 의제) 기준일의 유효 세율

[A] 케이스 판정 (11.1 바인딩 3단계, 03권 17.3). 위에서부터 먼저 맞는 것 채택
  1. payee.is_internal:  pipeline == 2.3 이면 TX-13, 아니면 TX-01             → DECIDED
  2. supply_category == GOODS:
       pipeline == 2.3 → TX-13 DECIDED
       book_supply_type 없음 → NULL, PENDING
       미등록 개인(예외 승인 건) → TX-12 PENDING
       그 외 도서 위탁 · 매입 → TX-11 DECIDED   (income_category NULL, taxable_base 생성 금지)
  3. NULL 보류 조건 하나라도 해당 → matrix_case_id = NULL, PENDING
       main_work_external_labor == true · is_resident == false(TX-10 격리) ·
       business_status != 계속 · tax_type_cd == 03 · 매핑 불가 코드 ·
       income_category 없음(재화 제외) · (OTHER and income_clause 없음)
  4. 개인(사업자등록 없는 프리랜서): supply_nature로 TX-02(강의 R/S · 매출연동 지원금) /
       TX-03(인세 · 매절) / TX-04(비정기 약정금)                           → DECIDED   [확인 필요 1번]
  5. tax_type_cd 매핑: 01→TX-07(법인 · 단체의 도서 인세 · 매절은 TX-09)  02→TX-05  07→TX-06  04→TX-08
       04 + 법인 + 면세요건 미충족 과세 용역 → 후보 TX-09/TX-07, PENDING
       05·06 → 후보 TX-09(인세 · 매절) / TX-07(그 외), PENDING
  6. 개인 과세사업자 TX-06·TX-07 인적용역 · 인세 · 지원금 라인(14.3 자문 확정 전) → PENDING(후보 유지)  [확인 필요 3번]
  PENDING이면: 세액 계산 안 함, taxable_base 보존, 마감 차단 표지. 종료.

[B] 부가가치세  (TX-06·TX-07·TX-09만 과세, TX-05·TX-08·TX-11은 0, TX-13은 Pipeline 2.3 값 인계)
  # 공급가액은 상계 전 금액(8단계 분할액) 기준 — 02권 L264 '공급가액 = 세전 지급액(상계 전 공급가액 기준)'
  # (2026-10-26 총괄 판정, SPEC Q-17 해소). 선급금 상계는 공급가액 · 부가세를 줄이지 않는다.
  VAT_EXCLUDED:  supply_value = split_amount                       # 상계 전
                 vat_amount   = floor(supply_value * 0.10)         # 부가세 1회 내림(13.1)
                 settle_with_vat = pre_tax_amount + vat_amount      # 세전 지급액(상계 후) + 부가세
  VAT_INCLUDED:  total = split_amount                              # 상계 전 총액
                 supply_value = floor(total * 100 / 110)
                 vat_amount   = total - supply_value               # 역산(13.2)
                 settle_with_vat = pre_tax_amount                  # 추가 가산 없음
  위탁(TX-11): consignment_fee_vat = floor(순 위탁 수수료 공급가액 * 0.10)
       NET_DEDUCT   → 위탁 실정산액 = 4단계 순 위탁 정산액 - consignment_fee_vat
       GROSS_SETTLE → 위탁 실정산액 = 4단계 순 위탁 정산액

[C] 원천징수  (재화 · TX-01 · TX-09 · TX-13 · 법인 TX-07은 호출하지 않음)
  if taxable_base < 0:  원천세 0, pending_negative_base 적재, 과세 보류
  elif income_category == BUSINESS:
      income_tax       = floor(taxable_base * 0.03)
      local_income_tax = floor(income_tax * 0.10)
      # 인적용역 사업소득은 소액부징수 제외: income_tax < 1000 이어도 그대로 징수

      deemed    = floor(U * deemed_expense_rate[income_clause])   # C15·C19 0.6 / C05·C17 0
      other_amt = U - deemed
      if other_amt <= 50000:  income_tax = 0, local_income_tax = 0       # 과세최저한
      else:
          income_tax       = floor(other_amt * 0.20)
          local_income_tax = floor(income_tax * 0.10)
          if income_tax < 1000: income_tax = 0, local_income_tax = 0     # 소액부징수(기타소득)
  total_withholding = income_tax + local_income_tax

[D] 9단계 실정산액
  payee 당월 9단계 실정산액 =
      (당월 신규 세전 지급액 - 당월 신규 원천징수세액 + 당월 부가가치세) + 위탁 실정산액
  # VAT_INCLUDED 라인은 부가세를 더하지 않음(확인 필요 5번)
  선급금 상계 비대상 보호 지급액(3단계 MMG 보전금 · 비상계 지원금 · 비정기 약정금의 세후 해당액)을
  보호분으로 태깅해 10단계로 전달

출력: income_tax, local_income_tax, vat_amount, 9단계 실정산액(상계 허용분 / 비상계 보호분),
      원귀속 PRE_TAX 세후 환산액, matrix_case_id, tax_decision_status, pending_negative_base
```

### 절사 위치 (13장, 줄 563~569)
- 중간 값은 DECIMAL(18,4) 유지, 단계마다 원단위 절사하지 않는다. 절사는 내림(Floor)만, 사사오입 · 올림 금지.
- 세액 절사 위치: 필요경비 내림 → (기타소득금액 판정) → 소득세 내림 → 지방소득세 내림(소득세액의 10%, 순차 2단). VAT는 공급가액 기준 1회 내림, VAT_INCLUDED는 공급가액 = 내림(총액 × 100/110), 부가세 = 총액 − 공급가액(역산, 13.2).
- 음수 라인: 절대값을 내림한 뒤 부호 복원(수학적 내림을 음수에 직접 적용 금지). 9단계는 음수 과세표준에 원천세를 산출하지 않는다(보류).
- 라인별 분리 절사, 마지막 항목 잔여 귀속은 8단계(수취인 분할) 영역(정렬 split_ratio 내림차순 → payee_id 오름차순).

## 정본 확인 필요

1. **개인 프리랜서(사업자등록 없음) 식별 기준 없음.** 03권 17.3절 `tax_type_cd`(01~07)에 개인 프리랜서 코드가 없고 `payee_tax_type` 값 목록에도 프리랜서 값이 없다. TX-02·03·04 진입 조건과 TX-02/03/04 구분 입력 필드를 정본이 정하지 않았다(11.1 입력 속성 줄 405, 2.1 줄 36). 의사코드 4번은 공급 성격 기준의 구현 가정이다. `supply_nature` 값 목록은 11.1 줄 405에 한글로만 있다.
2. **TX-05·06·07(개인)·08의 원천징수 판정 기준 공백.** "사업자 지위만으로 제외하지 않고 소득 성격과 적용 법령에 따라 별도 판정"(줄 462·468·474·481, 줄 414)이라고만 하고 조건 · 세율 · 소득 구분을 정하지 않았다. TX-06·07은 14.3 자문 확정 전 개인 인적용역 지급분을 PENDING으로 둔다(줄 409). 이 4개 케이스의 원천세는 `tax_table.json`에서 `withholding: UNDETERMINED`로 두고 계산하지 않는다. TX-05·08은 자문 대상으로 명시되지도 않아 보류 조건도 불명.
3. **PENDING 후보 조건(줄 409 ③, 535)의 범위.** "개인 과세사업자 TX-06·TX-07의 인적용역 · 저작권 사용료 · 개발지원금 라인"으로 열거했으나 강의 R/S · 매절 · 약정금(TX-07 공급 성격에 있음)이 포함되는지, 개인 / 법인 구분(`corp_no` 유무)과 "인적용역 해당"을 무엇으로 가르는지 정하지 않았다. 자문 확정 후 DECIDED로 풀리는 규칙도 없다.
4. **기타소득 판정 단위와 라인 단위 세액의 관계.** 9단계는 원천세를 "라인별 순차 계산"(줄 274)하고 과세최저한 · 필요경비는 `tax_threshold_unit_key` 판정 단위 합산 과세표준 기준(줄 266)으로 한다. 한 판정 단위에 여러 라인(복수 수취인 · 이월 라인)이 속할 때 단위 세액을 라인에 배분하는 방법(13.2 총액 역산 적용 여부)이 없다. 이월(PRE_TAX_CARRY) 라인과 당월 신규 라인이 같은 단위 키일 때 합산 여부도 불명.
5. **VAT_INCLUDED와 9단계 실정산액 식의 충돌 소지.** 부가세 반영 후 정산액은 VAT_INCLUDED에서 총액(추가 가산 없음, 줄 263)인데, 실정산액 식은 "세전 지급액 − 원천세 + 당월 부가가치세"(줄 282)로 VAT를 무조건 더한다. 세전 지급액이 총액이면 이중 가산된다. 의사코드는 INCLUDED에서 가산하지 않는 것으로 두었으나 정본 문구 정리가 필요하다.
6. **소액부징수와 지방소득세.** "소득세 기준 1천 원 미만이면 징수하지 않는다"(줄 279)이므로 소득세 0이면 지방소득세도 내림(0 × 10%) = 0으로 처리했다. 지방소득세 소액 징수면제는 특별징수분에 미적용(줄 280)이라고만 있다. 또 기타소득은 과세최저한(기타소득금액 > 50,000)을 통과하면 소득세가 최소 10,000원이라 소액부징수가 실제로 발동하지 않는다(모순은 아니나 도달 불가 분기).
7. **TX-07 자문 확정 전제 · TX-03 매절 면세 근거.** 정본이 자문(14.3)으로 둔 항목이다. 엔진은 지어내지 않고 TX-06·07 개인 라인을 PENDING으로 두며, TX-03 매절 면세는 "기준선, 개별 계약 자문 확인"(줄 441) 그대로 면세로 계산하되 `verification_status`가 미확인 등급이면 자동 마감 경로에서 제외(줄 530). 등급 값은 부록 C에 있으며 이 표에 옮기지 않았다.
8. **비과세 케이스의 `income_category`.** TX-11은 NULL로 명시, TX-13 · TX-12도 재화라 예외지만, TX-09(서비스 라인)와 TX-01은 `income_category`를 NULL로 둔다는 문구가 없다. 11.3 보류 조건 ②는 "income_category 미지정(재화 공급 라인 제외)"이므로 TX-09 · TX-01 서비스 라인이 PENDING에 걸릴 소지가 있다. 법인 · 단체 · 자사 라인의 income_category 입력 규칙을 정하지 않았다(의사코드 1번 · 5번은 NULL 보류 조건 3번 이전에 TX-01을 분기해 이를 피한 구현 가정).
9. **산출값 컬럼명.** 03권 데이터 사전에는 소득세 · 지방소득세 · 부가가치세 산출 컬럼명이 없다(`taxable_base`, `tax_threshold_unit_key`, `income_category` 등 입력 쪽만 있음). 임시로 `income_tax`, `local_income_tax`, `vat_amount`를 썼으며 SPEC.md 9단계 출력명과 맞춰야 한다.
10. **음수 처리 범위.** 9단계는 음수 과세표준을 `pending_negative_base`에 적재하고 원천세를 산출하지 않는다(줄 284). 13.1의 "절대값 내림 후 부호 복원"을 9단계에서 어느 값(VAT · 라인 금액)에 적용하는지는 단계별로 명시되지 않았다.
11. **유효 세율 기준일.** 원천징수는 "실제 지급(또는 적법한 상계 · 법정 지급 의제) 기준일의 유효 세율"(줄 274)을 쓰고 11.3 표는 규칙별 기준일을 달리 두라고 한다. 엔진 입력에 기준일 필드(`payment_event_date` 등)와 정산월의 연결 방법이 없다. 2024.7.1 이전 지급분의 소액부징수(TX-02) 처리도 정하지 않았다.
